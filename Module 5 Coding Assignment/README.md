# Module 5 Coding Assignment

## Goal
This project demonstrates a restaurant homepage where selecting **Specials** opens a randomly selected menu category. The previous special is excluded from the next choice when other categories are available, so consecutive clicks show a different category.

## Files
- `index.html` — responsive page structure and navigation
- `css/styles.css` — layout, colors, responsive styles, and reduced-motion support
- `js/script.js` — category data, random selection, and page rendering

## Run
Open `index.html` in a modern browser. No package installation or external service is required.

## Verify
1. Open the home page.
2. Click **Specials** or **Surprise me with Specials**.
3. Confirm a category page with menu items appears.
4. Click the restaurant logo or **Back to home**.
5. Click **Specials** again and confirm a different category appears.
6. Click **Menu**, open a category, and use **Back to home** to return.

## Notes
This is a self-contained implementation of the assignment's required behavior. The sample categories and menu items are local demonstration data; they do not represent a live restaurant menu.
